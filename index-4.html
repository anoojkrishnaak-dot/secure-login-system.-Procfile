🔒 Secure Login System

A cyber security project: a Python authentication system built with modern, industry-standard protections. Command-line and Flask web versions.

View source code Project report

Security features

scrypt hashing

Memory-hard hashing with a unique random salt per user and an optional server-side pepper.

Brute-force defence

Account lockout after 5 failed attempts, plus per-IP rate limiting on the web version.

Two-factor auth

TOTP (RFC 6238) compatible with Google Authenticator and Authy.

Injection safe

Parameterized SQL queries and autoescaped templates stop SQL injection and XSS.

No enumeration

Generic errors and a dummy-hash check hide which usernames exist.

Safe sessions

256-bit random tokens stored only as hashes, expiring in 15 minutes, with CSRF protection.
